# Mental Health Risk Prediction using Machine Learning

### CSRBOX – IBM SkillsBuild Applied AI Internship 2025

**SDG 3: Good Health and Well-Being**

A machine learning project that predicts potential mental health support needs using survey-based behavioral, lifestyle, and workplace factors.

## Model

* **Algorithm:** Random Forest Classifier
* **Dataset:** Mental Health Dataset
* **Train-Test Split:** 80:20
* **Evaluation:** Accuracy, Classification Report, Confusion Matrix, Feature Importance

## Technologies

Python · Pandas · NumPy · Scikit-learn · Matplotlib · Seaborn · KaggleHub · Google Colab

## Workflow

**Survey Data → Preprocessing → Feature Encoding → Random Forest → Risk Prediction**

The model classifies responses into **Low Risk** or **Needs Support** with a probability score.

> **Note:** This project is for educational and mental health awareness purposes only. It is not a medical diagnostic tool.

## Notebook

`Mental_Health_Risk_Prediction.ipynb`

The notebook can be run in Google Colab and downloads the dataset using KaggleHub.
